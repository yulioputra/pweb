# 🍲 Katalog Kuliner & Jajanan UMKM Nusantara

Projek website katalog kuliner interaktif buatan UMKM lokal berbasis HTML5 dan CSS3.

## 👥 Penyusun
**Yulio Putra P.**


---

## 🚀 Fitur Utama Website
* **Hero Banner**: Tampilan visual menarik dengan tombol *Call to Action*.
* **Tabel Katalog Produk**: Tabel responsif dengan efek *hover elevation* dan status stok harian.
* **Galeri Card Showcase**: Tampilan kartu interaktif lengkap dengan penanda produk (Terlaris/Promo).
* **Integrasi WhatsApp**: Tombol pemesanan langsung terhubung ke nomor WhatsApp UMKM.
* **Desain Responsif**: Layout menyesuaikan tampilan HP, Tablet, dan Desktop.
